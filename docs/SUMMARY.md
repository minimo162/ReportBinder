# UI/UX レビュー要約（2026-11-03）

詳細は [uiux-review.md](uiux-review.md)。

## 全体
- 見た目・余白・文字サイズは一貫しており、「次にやること」を常に出す導線もよくできている
- ただし初回利用で最初に通る場所に、**失敗理由が出ない**経路と、**警告に見えるだけの表示**が残っている

## P0
- 原稿の登録に失敗すると「詳細を確認してください」とだけ出て、詳細はどこにも表示されない（非表示のログに書かれるだけ）
- 失敗後はチェックが全部外れ、選び直しが必要

## P1
- 原稿0件の初回起動で、ステップ1が警告の「!」になる
- 登録のあと、選択0件でも「選択した原稿を登録」ボタンが押せる状態に戻る
- 原稿フォルダーのパスが末尾で切れ、肝心のフォルダー名が見えない
- 一式メニューに「パック」という別の呼び名が残っている
- ページ構成の操作バーで「変更分のみ」などが1〜2文字ずつ折り返して潰れる
- 変更履歴・比較で原稿0件のとき、なぜ選べないかの説明がない
- PDFプレビュー枠の読み上げ名が英語（"PDF preview"）

## P2
- ホームに同じ流れ図が2つある／段階の呼び名が画面ごとに違う
- 一式作成ダイアログで「今回まとめる一式」が3回続く
- 未登録原稿が更新日時順（番号付きファイル名なら名前順が見やすい）
- 原稿0件でも「変換PDFをすべて作り直す」が出ている
- ページ構成の案内文が長く、操作説明が重複している
- `style.css` に上書きの層が積み重なり、崩れの原因を追いにくい

## 今回直すもの
- P0 と P1 すべて（小さく安全な変更のみ）

## 持ち主の判断が要るもの
- 段階の呼び名の統一、ホームの流れ図の整理、未登録原稿の並び順の既定
- ページ構成の操作バーを2段にするか（現状は1行固定が設計判断）
- `style.css` の整理、警告トースト全般に「詳細を見る」導線を作るか
