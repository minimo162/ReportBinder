# PDF差分品質コーパス

実務で遭遇するPDFの種類ごとに、差分検出の見逃しと誤検出を継続測定する回帰試験である。固定のバイナリPDFは保存せず、ReportLabで決定的に生成し、配布版と同じPDFBoxで72 DPIのBMPへ描画したうえで、ブラウザー版と同じ`diff-worker.js`を実行する。

## 対象

- 文章だけの報告書
- 履歴書・申請書に近い罫線帳票
- 複雑な表、列構成変更、表外の追記が混在する資料
- 横向きの図表・ダッシュボード

各ケースは期待変更領域を正規化座標で持つ。期待領域を検出できた割合をrecall、検出領域のうち期待領域へ対応した割合をprecisionとして扱う。現行ゲートはrecall 100%、precision 60%以上であり、同一PDF同士の比較では差分領域が0件でなければ失敗する。

## ページ対応と残余リスク

サーバー側の実PDF回帰では、次のページ列も正方向・逆方向で検証する。

- 自動ページ番号が変わる途中ページ挿入
- 全面テンプレート変更と途中ページ挿入の併発
- 全面書き換えと削除＋追加を区別できない場合の「対応不確実」判定
- 完全に同一な重複ページの追加・削除件数と位置不確実性
- 異なるスキャンノイズだけの抑制と、ノイズ中の実チェック記入の検出

数百ページ級は通常CIから分離して実測する。2026-08-08の220ページ正逆・同一版（662ページ対応）では、ページ距離計算のC#移行後に約27秒で完了した。

## 実行

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\tools\pdf-diff-corpus-selfcheck.ps1
```

生成物を目視確認する場合は`-KeepTestData -TestRoot <path>`を指定する。通常のCIでは一時ディレクトリを自動削除する。
